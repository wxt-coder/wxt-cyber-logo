# WXT Cyber Coder 品牌 Logo

本仓库包含王现天（WXT）Cyber Coder 的赛博风格 Logo，以 SVG 矢量格式提供，适用于高分辨率显示、动态交互及多场景展示。

## 📁 文件说明

- `wxt_cyber_logo.svg` – 主 Logo 文件（矢量），包含完整的故障特效与霓虹效果。

## 🎨 设计理念

Logo 以 **赛博朋克** 与 **数字全息** 为基调，融合未来科技感与编程文化，展现 **王现天（WXT）** 在技术领域的先锋形象。

### 核心元素

| 元素 | 含义 |
|------|------|
| **故障偏移文字（WXT）** | 洋红与青蓝双层错位，象征数据流与数字世界的动态不稳定，体现 “Cyber” 基因 |
| **霓虹发光** | 赋予文字科技感与视觉张力，呼应赛博朋克美学 |
| **HUD / 瞄准线** | 中心十字与圆环标尺，代表精准、专注与系统级思维 |
| **电路走线与边框** | 四角电路路径，隐喻连接、传输与硬件底层 |
| **背景网格与二进制数字** | 致敬传统黑客文化与数字原生环境，强化“Coder”身份 |
| **扫描线与暗角** | CRT 显示器效果，唤起复古终端与沉浸式体验 |

整体设计强调 **未来、极客、系统美学**，适合用于个人品牌、技术博客、开源项目、或数字作品集。

## 🎯 色彩规范

| 颜色名称 | 色值（HEX） | 用途 |
|----------|-------------|------|
| 青蓝（Primary） | `#00f3ff` | 主轮廓、十字线、发光核心、文字偏移层 |
| 洋红（Accent） | `#ff00c8` | 辅助轮廓、故障偏移层、高亮元素 |
| 纯白（Base） | `#ffffff` | 中心文字（叠加霓虹滤镜） |
| 深空背景（Dark） | `#0a0b14` 至 `#1a2b3c` | 基底渐变，营造深邃感 |

## 📐 使用建议

### 在网页中嵌入

```html
<img src="wxt_cyber_logo.svg" alt="WXT Cyber Coder Logo" width="800" height="500" />
```

或直接内联 SVG 代码以实现更精细的控制（如动画、交互）。

### 在 Markdown 文档中引用

```markdown
![WXT Cyber Coder Logo](./wxt_cyber_logo.svg)
```

### 尺寸与缩放

SVG 原始尺寸为 `800×500`，支持任意比例缩放，建议保持宽高比 `1.6:1`。最小使用尺寸建议不低于 `200×125`，以保证故障细节清晰可见。

## 🧩 自定义与扩展

- **文本替换**：若需修改文字内容，可直接编辑 SVG 中的 `WXT` 文本节点（共三处：洋红层、青蓝层、白色发光层），并同步调整故障偏移量 `dx`/`dy` 以获得最佳效果。
- **颜色主题**：可全局替换青蓝（`#00f3ff`）与洋红（`#ff00c8`）为自定义品牌色，但需保持对比度与发光氛围。
- **动画增强**：SVG 已内嵌光标闪烁动画，可进一步添加数据流流动、旋转光环等 CSS/SMIL 动画，提升动态表现。
